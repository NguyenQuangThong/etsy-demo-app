Planned Etsy API usage

Only the data required for seller workflow screens.

The app will request Etsy API access to display seller-owned shop data, not to scrape, resell, or expose marketplace data. The initial public version is read-focused and intended for a single connected shop owner.

Data handling

Clear, minimal, seller-controlled access.

  • Access is limited to the connected seller's shop workflow.
  • No buyer contact data is shown unless needed for order fulfilment.
  • No data is sold, shared with advertisers, or used for marketplace scraping.
  • Users can disconnect their shop and request data removal.
